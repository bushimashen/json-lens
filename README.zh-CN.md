# JSON Lens

**[English README](README.md)**

粘贴任意 JSON，一键生成**可交互的思维导图**——对象、数组、字符串、数字、布尔、null 各有专属配色。大文件靠折叠分支、缩放平移自由探索，最终可导出高清 PNG 或矢量 SVG。

**全部处理 100% 在浏览器本地完成。无服务器、无上传、无追踪——数据绝不离开本页。**

![浅色主题](docs/screenshot-light.png)
![深色主题](docs/screenshot-dark.png)

## 功能特性

- 🗺 **JSON → 导图一步到位**——粘贴、打开 `.json` 文件、或直接把文件拖进页面任意位置；输入防抖自动渲染
- 🎨 **类型分色节点**——对象（蓝）、数组（青）、字符串（绿）、数字（琥珀）、布尔（粉）、null（灰）
- 🖱 **交互探索**——点击节点折叠/展开（`+N` 徽标提示隐藏了多少子孙节点）；滚轮以光标为中心缩放、拖拽平移、一键「适应」
- 🔍 **巨型载荷保护**——超过 12 层的分支、超过 200 项的兄弟列表自动截断并显示 `… 已省略` 提示节点，10 MB 的接口 dump 也不会卡死布局
- 🖼 **导出**——2 倍分辨率 PNG 或真矢量 SVG，按当前主题配色烘焙
- 🌓 **明 / 暗主题**——记忆你的选择，首次访问跟随系统偏好
- 🌐 **中英双语界面**——按浏览器语言自动选择，一键切换
- 📦 **零依赖、零构建**——单个 `index.html` 文件，`file://` 直接打开、可离线使用

## 快速开始

无需安装、无需构建：

1. 下载本仓库（或只下载 `index.html` 一个文件）
2. 双击 `index.html` —— 完事

想用本地服务跑（可选）：

```bash
cd json-lens
python -m http.server 8000        # 或：npx serve
# 打开 http://localhost:8000
```

### 使用方法

| 操作 | 方式 |
| --- | --- |
| 载入 JSON | 粘贴到编辑框 / 点「打开文件」/ 把 `.json` 文件拖到页面任意位置 |
| 折叠 / 展开分支 | 点击节点（隐藏子级时出现 `+N` 徽标） |
| 缩放 | 滚轮（以光标为中心）或 − / ＋ 按钮 |
| 平移 | 在画布上拖拽 |
| 适应视图 | 「适应」按钮 |
| 全部收起 / 展开 | 工具条按钮 |
| 格式化输入 JSON | 「格式化」按钮 |
| 导出 | 「下载 PNG」/「下载 SVG」 |
| 主题 / 语言 | 右上角 🌓 / EN 按钮 |

### 说明

- 为可读性做了截断：超过 24 字符的字符串会以 `…` 截断显示
- 解析错误会内联显示浏览器原始报错信息，方便快速定位修数据
- 整个应用就是一个自包含的 HTML 文件（约 34 KB）——审计方便，放哪都能跑（GitHub Pages、对象存储、公司内网……）

## 实现原理（30 秒版）

`index.html` 内部分三层：

1. **解析与整树**——`JSON.parse` 输入，递归转成 `{label, type, children}` 树（带深度/兄弟数保护）
2. **布局**——经典横向 tidy 树排布，计算 x/y 坐标（固定行高、实测标签宽度）
3. **渲染与交互**——原生 SVG DOM 节点，指针事件处理折叠、平移、以光标为锚的缩放；导出时克隆 SVG 并烘焙主题色

无框架、无虚拟 DOM、无状态库——约 700 行零依赖 JavaScript。
